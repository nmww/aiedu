## 维护说明

!!! tip "怎么新增一个项目"
    1. 把项目封面图放到 `docs/assets/covers/` 下（建议宽度 900px、JPEG 格式）
    2. 在 `docs/works/index.md` 里复制一张卡片，改名称、简介、技术标签和链接
    3. 在首页 `docs/index.md` 的「全部作品」表格里补一行
    4. 在本页顶部加一条更新记录
    5. 提交推送后，文档站会自动重新构建

    重点项目的详情页放在 `docs/works/<项目名>.md`，并在 `mkdocs.yml` 的 `nav` 里登记。
