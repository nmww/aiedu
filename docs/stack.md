## 选型习惯

**优先选能一个人维护的。** SQLite 而不是 PostgreSQL，静态托管而不是自建服务器——不是性能不够，是运维成本要算进去。一个能长期稳定跑着的小方案，比一个先进但没人顾得上的方案强。

**对平台保持可迁移性。** 不把业务逻辑写进某个平台的专有配置里。容器镜像、环境变量、标准 HTTP 接口——这些换到哪个平台都能用。

**接口按标准来。** 向量化服务做成 OpenAI 兼容格式，模型调用走统一抽象层。这样换供应商的时候，改动被限制在一层之内。
