# 盛通教育 · 画中学

![画中学](../assets/covers/huaxuezhong.jpg)

!!! quote "一句话"
    一块手绘风的白板，让抽象的思考过程「看得见」。

**访问站点**：[modeai-huaxuezhong.ms.show](https://modeai-huaxuezhong.ms.show) · **技术栈**：Excalidraw · 静态托管

---

## 为什么做这个

学生「不会」，很多时候不是因为没记住，而是**因为想不清楚**。

数学题的等量关系、一篇作文的结构、一个知识点的脉络——这些东西在脑子里是模糊的，用文字写下来又太线性。而画出来就具体了：画的过程本身就是整理思路的过程。

画中学基于开源项目 Excalidraw 做了教育场景的深度定制，把「手绘」这个动作变成一种学习方法。

---

## 核心能力

| 模块 | 说明 |
| --- | --- |
| **手绘白板** | 原生手绘笔触 + 无限画布，接近真实纸笔的手感，不受屏幕大小限制 |
| **连环画创作** | 用分镜的方式把一个过程或故事画出来，适合语文、科学的表达训练 |
| **思维导图** | 梳理知识脉络，把零散的知识点连成结构 |
| **解题四步框架** | 内置解题步骤模板，引导学生按「读题 → 找关系 → 列式 → 检验」的节奏思考 |
| **每日挑战** | 每日练习题模块，形成稳定的练习节奏 |
| **教学贴纸库** | 丰富的教学素材贴纸，降低绘画门槛——不会画也能表达 |
| **个人作品集** | 学生作品自动归档，形成可回顾的成长记录 |

## 设计上的取舍

**保留手绘质感，而不是做成规整的图表工具。**
专业的图表工具能画出很标准的图形，但那要求学生先学会用工具。手绘风的好处是**容错**——画歪了、画丑了都不影响表达，学生更敢下笔。重要的是思考过程被外化，不是画得好看。

**贴纸库解决「不会画」的障碍。**
低年级学生表达意愿强但绘画能力有限。预置贴纸让他们能直接调取需要的元素，把精力放在「想表达什么」而不是「怎么画出来」。

**作品集让学习有沉淀。**
单次作业交完就结束了，但作品集让一学期的思考轨迹保留下来。学生能看到自己的变化，老师也能看到思维发展的过程。

## 技术实现

项目基于 Excalidraw 二次开发，以静态站点形式部署——没有后端依赖，加载即用，维护成本低。

选择静态部署的原因：白板本身是纯前端能力，数据存在浏览器本地，加一层服务端反而增加复杂度和故障面。**能用静态方案解决的，就不要引入服务端。**
